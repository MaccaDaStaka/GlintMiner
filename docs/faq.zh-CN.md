## 常见问题

**对显卡安全吗？** 在默认设置下，GlintMiner 从不改动频率、电压或风扇。它一直监控每张显卡的温度，显卡过热时调低功耗上限（这需要管理员权限），显卡接近关机温度时暂停它，冷却后再继续。只有开启[自动调校](auto-tune.zh-CN.md)后才会改动频率，GlintMiner 关闭时一切都会恢复。

**矿机调校要好几个小时，这期间所有显卡都以满功耗运行吗？** 不会。显卡逐张调校，每张大约 1–2 小时。排队等待的显卡如果有你自己的超频就保持它，否则在轮到之前以默认功耗上限的四分之三挖矿；面板会显示整台矿机需要多长时间。要在调校期间限制矿机总功耗，可以设置功耗预算（**设置 → 温度和功耗**，或 `--tune-power-budget`）。详见[多显卡矿机](auto-tune.zh-CN.md#多显卡矿机)。

**我能赚多少？** 这取决于你的显卡、Pearl 价格和全网难度，这些都在不断变化。GlintMiner 从启动那一刻起就实时显示你真实的每日收益，填入电价后还会显示扣除电费后的利润。面板的收益页面还会按今天的数据预测未来 7 天和 30 天的收益。

**为什么矿池显示本机的算力更低（或为 0）？** 矿池报告的是过去约 30 分钟的平均值，每隔几分钟刷新一次。刚启动（或重启）GlintMiner 后的 10–30 分钟内，矿池可能显示本机为 0 或旧的数值。运气也会让矿池的数值每小时上下波动；按一天来看就会拉平。GlintMiner 自己的算力是直接在你的显卡上测量的。

**挖矿时还能用电脑吗？** 可以，但运行时游戏和视频剪辑会变慢，同时也会拖慢挖矿。需要显卡全部性能时，关闭 GlintMiner（关闭窗口或按 Ctrl+C）即可。[自动调校](auto-tune.zh-CN.md#开始之前)进行调校时，不要用电脑做繁重的工作。

**需要以管理员身份运行吗？** 不需要，不用管理员权限也能正常挖矿。只有在显卡过热时降低功耗上限，以及使用自动调校时，才需要管理员（Linux 上为 root）权限。

**1% 开发者抽水具体是怎么回事？** 每张显卡大约每一百秒中有一秒为开发者挖矿。它会实时显示，包括目前为止实际抽取的数量，除此之外绝不收取任何费用。见 [README](../README.zh-CN.md#1-开发者抽水公开透明)。

**为什么 GlintMiner 时不时会连接 HeroMiners（或其他矿池）？** 那是 1% 开发者抽水：它通过自己单独的连接在自己的矿池上挖（HeroMiners，Kryptex 作备用），与你的矿池和钱包互不相干。日志中它的每一行都以 *dev fee (1%)* 开头，并且只显示状态变化（已连接、正在重连、空闲）；日常细节写入 `glint.log`。如果它的矿池被拦截，抽水会以抽水地址通过你自己矿池的服务器进行；如果这样也不行，就把 1% 的时间空闲。绝不会超过 1%。

**控制台显示 “fee pools unreachable: 1% of time left idle”。** 抽水服务器（以及它在你自己矿池服务器上的备用连接）无法连接，通常是防火墙或 DNS 过滤拦截了它们，所以那 1% 的时间改为空闲，而不是挖抽水：拦截并不能省下什么。放行 `pearl.herominers.com` 和 `prl.kryptex.network`（或你自己矿池的服务器）后，抽水就会恢复挖矿。如果持续被拦截一整天，挖矿会暂停，直到它能连接为止（见下一个问题）。

**挖矿已暂停：“开发费无法连接”。** 如果开发者抽水连续 24 小时没有可用的连接（它自己的服务器以及它在你矿池服务器上的备用连接都不行），而你自己的矿池是正常的，GlintMiner 会暂停所有显卡的挖矿，并在控制台、日志和面板中说明。它会在后台继续尝试抽水的服务器，只要抽水能通过其中任何一个连接，挖矿就会自动继续；不需要重启任何东西。重启 GlintMiner 不会让这 24 小时重新开始；只有抽水连接成功后才会重新计时。如果你自己的矿池也连不上（网络断了），那是断网，不是拦截：它永远不会计入这 24 小时，此时也绝不会因为抽水而暂停挖矿。

如果提示说*此电脑的时钟不正确（显示为 ...）*，那么并没有任何拦截：抽水的服务器用只在两个日期之间有效的证书证明自己的身份，电脑日期偏差很大时会把它们看作已过期或尚未生效（你自己的矿池仍然正常，因为矿工软件不检查矿池证书）。请设置正确的日期、时间和时区（最好开启自动设置时间）；抽水会在下一次尝试时连接，挖矿随即继续。

解决办法是放行抽水：
- 在防火墙、路由器、杀毒软件或 DNS 过滤（Pi-hole、AdGuard、家长控制过滤）中放行 `pearl.herominers.com:1200` 和 `prl.kryptex.network:8048`（或你自己矿池的服务器，抽水的备用连接会用它）。
- 在屏蔽或污染 DNS 的网络中（中国大陆、一些办公网络），常规解析失败时，抽水已经会通过安全 DNS 查找它的服务器。`--dns-over-https on`（或在 `glint.json` 中设置 `"dns_over_https": "on"`）会优先使用安全 DNS，对抽水和你自己的矿池都有效；`auto` 只在常规地址失败时才对你的矿池使用它。
- `glint --net-test pearl.herominers.com:1200`（以及 `prl.kryptex.network:8048`）会显示该服务器能否连接，以及你的网络 DNS 和各个安全 DNS 解析器的应答。

在它连接成功之前，控制台会显示 *Dev fee 1%: can't connect for a day: mining paused until it can*。

**什么是推荐码？** 推荐你使用 GlintMiner 的人的代码。可以在首次设置时、在**设置 → 推荐码**中、用 `--affiliate 推荐码`（HiveOS 和 mmpOS：加到额外参数里；`--affiliate off` 可删除）或在 `glint.json` 中用 `"affiliate"` 填写；GlintMiner 重启后生效。你仍然只付 1%：其中四分之一（0.25% 的时间）改为挖到推荐人的 PRL 钱包，而不是开发者的，所以你绝不会多付。推荐码来自单独的公开仓库（[GlintMiner-affiliates](https://github.com/MaccaDaStaka/GlintMiner-affiliates)）中的列表，用一把只用于推荐码列表的密钥签名，在你的矿机上校验；不会为此发送任何关于你的信息。如果面板或日志显示推荐码*无法识别*，说明它不在列表中（请检查拼写，或询问给你推荐码的人）：这时 1% 全部归开发者。如果推荐人的那部分无法连接，也改归开发者：绝不会变成空闲时间，也绝不会多抽。正常工作时，面板显示*推荐人：推荐码*，控制台显示 *affiliate: 推荐码*。你不能使用自己的推荐码：挖矿到该推荐码自身钱包的矿机，1% 全部归开发者。如果 GlintMiner 连续 14 天无法访问 GitHub，会提示*推荐码列表已过期*，在恢复之前 1% 全部归开发者。

**如何成为推荐人？** 在**设置 → 成为推荐人**中申请，没有屏幕的矿机可以用 `glint --become-affiliate`。每台使用你推荐码的矿机，其抽水的四分之一归你，由矿池支付到你的 PRL 钱包。发送之前你会看到将发送的全部内容：你填写的 PRL 收款钱包、你填写的 Discord 用户名（如有）、此安装的匿名 id 和 GlintMiner 版本；在你勾选确认（或输入 `yes`）之前不会发送任何内容。Discord 用户名是可选的，但要在 [Discord](https://discord.gg/dXBTwVzJNy) 上获得推荐人身份组和频道就需要它（2–32 个字符：小写字母、数字、`_` 和 `.`）。开发者逐一人工审核；通过后 Discord 机器人会给你身份组，你也会拿到推荐码，推荐码列表会在几分钟内自动签名并发布；正在运行的矿工会在启动时或一天之内获取它。面板（或再次运行 `--become-affiliate`）会显示申请是等待中、已通过还是未通过。

**GlintMiner 会自动更新吗？** 只有在你允许时才会。默认情况下，有新版本时它会提醒你，在你点击**立即更新**后安装；开启自动更新（设置 → 更新）后，它会在没有显卡处于调优过程中时安装。无论哪种方式，都只安装用 GlintMiner 发布密钥签名的版本，在你的矿机上运行不正常的版本会被回退。见[更新](../README.zh-CN.md#更新)、[如何更新](getting-started.zh-CN.md#更新)。

**我有多台矿机用同一个钱包。** 给每台矿机起不同的矿工名（`--worker rig2`，或 设置 → 挖矿）。矿池会分别列出每台矿机，面板的收益页面也会全部显示。

**支持 AMD 或较老的 NVIDIA 显卡吗？** 不支持。需要 NVIDIA RTX 20、30、40 或 50 系列显卡（计算能力 7.5 或更新，带 Tensor Core）。GTX 显卡（包括 GTX 16 系列）不受支持。

**它会收集我的数据吗？** 不收集个人数据。抽水份额带有一个匿名标签（显卡型号与数量、结算方式、版本、是否已调校）；从 1.2.8 起，GlintMiner 每 15 分钟发送一次匿名签到（同一个 id、版本、操作系统、显卡、算力、功耗、温度、份额数、GPU 错误、上次运行如何结束及原因、过去 24 小时的自行重启次数、自动调校的状态、模式、阶段和剩余时间、抽水状态、更新设置、驱动版本，以及你填写的推荐码）。绝不包含你的钱包、矿机名、矿池、IP 地址、位置或调校设置。[具体发送什么、为什么](../README.zh-CN.md#匿名签到)；用 `--no-telemetry` 或在 `glint.json` 中设置 `"telemetry": false` 即可关闭签到。面板运行在你的电脑上。

## 故障排除

| 你看到的情况 | 可能的原因 | 该怎么做 |
|---|---|---|
| **“Windows 已保护你的电脑”** | Windows SmartScreen，针对下载量还不多的程序 | **更多信息 → 仍要运行**（只需一次） |
| **杀毒软件删除或阻止了它** | 杀毒软件把加密货币挖矿软件整类标记 | [校验下载文件](#校验下载文件)，然后在杀毒软件中允许它 |
| **GlintMiner 找不到可以挖矿的显卡** | 不是 RTX 20/30/40/50 显卡，或 NVIDIA 驱动缺失或过旧 | 更新 NVIDIA 驱动；用 `glint --gpu-info` 检查 |
| **算力比预期低** | 其他程序在占用显卡（游戏、视频或动态壁纸、播放视频的浏览器标签页、AI 应用），或显卡温度过高 | 关闭这些程序；在面板上查看温度；保持显卡通风顺畅 |
| **控制台提示无法连接矿池** | 网络或 DNS 问题，或防火墙 | 检查电脑的网络；GlintMiner 会自动重试并切换矿池。`glint --net-test host:port` 可以测试矿池 |
| **份额被拒绝** | 很少见；通常是其他工具的超频不稳定 | 把其他超频工具恢复为默认。GlintMiner 在发送前会检查每个份额 |
| **“调优还无法开始”** | 没有以管理员身份运行 | 关闭 GlintMiner，右键点击，选择 **以管理员身份运行** |
| **“MSI Afterburner 正在运行”**（或其他工具） | 这个工具可能在调校期间改动频率 | 关闭它；调校会自动开始 |
| **调校结果看起来偏低** | 调校期间电脑在忙别的事 | 让电脑保持空闲，然后 **重新调优这张显卡**（矿机） |
| **显卡被暂停：“驱动程序已停止响应 — 请重启电脑以恢复此显卡”** | 显卡的驱动已半小时没有应答（GPU 出错之后）；其他显卡继续挖矿 | 重启电脑。如果驱动自己恢复了应答（Windows 可以重置它），这张显卡无需重启就会继续挖矿 |
| **显卡被暂停：“接近关机温度”** | 显卡温度非常高 | 改善通风、清理风扇，或设置更低的温度上限；降温后会自动恢复 |
| **手机上打不开面板** | 还没有允许，或被防火墙阻止 | 见[手机查看](phone-access.zh-CN.md#打不开时) |
| **矿池显示本机为 0** | 矿池滞后 10–30 分钟 | 等一等；见上面的问题 |
| **调校后黑屏或电脑死机** | 对这张显卡来说，这天的调校结果太激进了 | GlintMiner 下次启动时会自动回退调校结果。如果再次发生，请关闭调校或选择更省电模式 |

还是解决不了？运行 `glint --self-test`，并查看[获取帮助](#获取帮助)。

## 校验下载文件

每个版本在发布页面的 `SHA256SUMS.txt` 中列出了每个文件的 SHA-256 校验值。校验方法：

- **Windows**（在 PowerShell 或命令提示符中，在文件所在的文件夹里）：`certutil -hashfile glint-1.2.7-windows.zip SHA256`（或 `glint.exe`）
- **Linux：** `sha256sum glint-1.2.7-linux.tar.gz`（或 `glint`）

先确认 `SHA256SUMS.txt` 本身来自 GlintMiner：从 1.2.8 起它带有签名（见 README 中的[校验下载文件](../README.zh-CN.md#校验下载文件)）。结果必须与 `SHA256SUMS.txt` 中该文件那一行一致。如果不一致，不要运行它：请从 [Releases 页面](https://github.com/MaccaDaStaka/GlintMiner/releases)重新下载。请只从本仓库下载 GlintMiner。

## 调校后显卡更热

**我让它通宵调校后，显卡更热、功耗更高了，为什么？** 自动调校只有在你开启某个模式时才会运行；默认是关闭的。“算力最高”（`speed`）是追求挖到最多 Pearl 的模式，为此显卡可能得到比默认更高的功耗，最高到显卡自身的上限，除非你允许得少一些。在多卡矿机上它一次调校一张显卡，要花几个小时；排队等待的显卡以较低功耗运行，或保持各自的设置（在 HiveOS 上是你的超频），所以矿机在调校期间看起来更凉，等每张显卡都运行各自的调校设置后，功耗会更高。温度上限一直有效：达到上限的显卡会少拿一点功耗，并保留它的调校结果。

该怎么做：

- **允许更少的额外功耗。** **设置 → 温度和功耗 → “算力最高”可增加的功耗**（或 `--speed-power-raise none|low|medium|max`）：选*不增加*时，功耗绝不会高于默认。它对已经调校好的显卡同样有效，无需重新调校。
- **保留你自己的 HiveOS 超频。** 把调校设为 **关闭**（**设置 → 调优 → 关闭**，或 `--tune off`；在 HiveOS 上，从 **Extra config arguments** 中去掉 `--tune`）。模式为“关闭”的显卡会完全保持 HiveOS 设置的样子，而关闭调校会立即恢复 GlintMiner 改动过的一切。
- **想要更凉。** 用 **更省电**（同样的算力、更低的功耗）或 **凉爽安静**（以部分算力换取明显更低的功耗、温度和风扇噪音）代替“算力最高”。**收益最高**会按你的电价在“算力最高”和“更省电”之间选择。
- **看看每个模式会怎样。** 在面板上，排队等待的显卡的“较低功耗”标签旁的 **为什么？** 会解释原因；**比较模式**（矿机页面显卡模式旁，或设置 → 调优中）把各模式并排列出，显示你的显卡的 TH/s、瓦数和按你的电价计算的每天利润。它只用于查看，不会改变任何东西。

详见[多显卡矿机](auto-tune.zh-CN.md#多显卡矿机)。

## 获取帮助

提交 [issue](https://github.com/MaccaDaStaka/GlintMiner/issues)，并附上：

- 你的显卡型号和 NVIDIA 驱动版本，
- 你的操作系统，
- `glint --self-test` 的输出，
- `glint.log`（在程序旁边）中的相关内容。

如果不想公开你的钱包地址，请在粘贴的内容中把它删掉。

帮助与交流：[Discord](https://discord.gg/dXBTwVzJNy)。需要针对你自己矿机的帮助时，在 #private-help 频道点击 **Get help**，会开启一个私密话题。
