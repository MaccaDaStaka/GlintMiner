# 面板

[← 返回 README](../README.zh-CN.md) · [English](dashboard.md) · [Русский](dashboard.ru.md) · **简体中文**

GlintMiner 运行时，会在你自己的电脑上提供一个面板，地址是 **http://127.0.0.1:4078**。它可以在 GlintMiner 启动时自动打开（设置 → 面板）。不会向任何网站发送数据：页面只与你电脑上的 GlintMiner 通信，由 GlintMiner 向你的矿池和一个价格网站查询你的数据。

面板在手机和电脑上都能用，支持 **English、Русский 和简体中文**，有浅色和深色两种主题。

## 首页

首页按轻重缓急回答四个问题：

1. **运行正常吗？** 顶部的一行状态。一切正常时为**绿色**（例如 *挖矿中 · 在 Kryptex · RTX 4090 · 331 TH/s · 已接受 49/49 个份额*）。需要你处理时为**黄色**或**红色**，用一句话写明原因以及该做的那一件事。显卡调校期间也会在这里说明，并显示进度。 **游戏中，挖矿已暂停** 会写出让挖矿暂停的游戏（如果它不是游戏，可点 **不因 … 暂停**），**按计划暂停** 会说明何时继续挖矿。
2. **我赚了多少？** 扣除电费后的每日利润（未填电价时为每日收入），以你的货币和 Pearl 显示，另有*今天到目前*和*过去 7 天*。这是本机的估算，根据你的实时算力、全网情况和今天的 Pearl 价格算出；*计算方法*会列出用到的每一个数字。
3. **显卡发挥到最好了吗？** 如果自动调校未开启，会说明你的显卡以出厂设置运行（这完全没问题），并提供设置调校的入口。调校期间：已完成的百分比、剩余时间和已用时间。调校完成后：结果，例如 *已调优 +7.4%*，以及与出厂相比的算力和功耗。见[自动调校](auto-tune.zh-CN.md)。
4. **什么时候到账？** 你在矿池的余额、离下次支付还差多少、大约什么时候支付，以及上一笔支付。

下方的 **详细信息** 包括实时算力及其 24 小时图表、功耗、能效（每瓦 TH/s）、今日耗电、最热的显卡及其温度上限，以及你的份额（已接受、拒绝、过期）。

## 收益

- **今天、7 天、30 天、全部：** 所选时段的利润、收入、电费、挖到的 Pearl、挖矿时长和每日平均。每个数字都按当天的价格计算。
- **过去 30 天**的图表（收入、电费、利润和矿池支付），也可切换为表格。
- **如果保持不变：** 按今天的价格、全网难度和你的电价预测未来 7 天和 30 天的收益。Pearl 的价格每天都在变，所以这只是参考，不是承诺。
- **你的钱包：** 矿池针对你地址的数据：余额、最低支付额以及下次支付的大致时间。在 Kryptex 上，还会显示已确认和仍在成熟中的部分。
- **这个钱包下的矿机：** 挖到同一地址的每台矿机，以及矿池看到的各自算力和本机在总算力中的占比。
- **支付记录：** 最近的几笔支付，包括金额、时间、交易链接以及按你的货币计算的价值。**显示全部** 列出其余记录，**在 … 查看完整记录** 会打开矿池自己的支付页面。

## 矿机

- **每张显卡**单独显示：算力、温度与其上限、功耗与其功耗上限、已接受的份额，以及调校状态（模式、进度或结果）。
- **逐卡控制**（开启自动调校时）：暂停某一张显卡的调校、重新调校某一张显卡，或为它设置单独的模式。
- **最近事件：** 值得知道的事，例如显卡启动或重启、矿池连接或切换、调校完成或回退，以及错误。例行记录（每个被接受的份额、每分钟的算力）不在这里显示，以免淹没重要的信息；份额计数在首页。

## 设置

| 分区 | 内容 |
|---|---|
| **钱包和结算** | 你的地址或 Kryptex 账户，以及收益如何到账 |
| **电费** | 每千瓦时电价和货币，用于计算电费和扣除电费后的利润 |
| **调优** | 自动调校开启或关闭和矿机的选项（收益最高、算力最高、更省电、最凉最静），以及每张显卡的选项（见[自动调校](auto-tune.zh-CN.md)） |
| **游戏与计划** | 玩游戏时暂停（Windows）及不会触发暂停的程序；为某些时段选择另一种模式或暂停（见[游戏与计划](auto-tune.zh-CN.md#游戏与计划)） |
| **温度和功耗** | 温度上限（自动取自显卡，或自行设置）、紧急暂停，以及用于功耗上限的利润模式 |
| **面板** | 谁可以打开（仅本电脑，或其他设备仅查看）、端口，以及启动时是否打开 |
| **外观和语言** | 浅色、深色或自动主题，以及语言 |
| **Telegram 提醒** | 显卡停止或矿池断开时发消息给你 |
| **挖矿**（高级） | 矿机（矿工）名称、使用哪些显卡，以及自定义矿池 |
| **控制台和日志** | 适用于服务和矿机系统的简洁控制台，以及是否写入 `glint.log` |

更改会保存到 `glint.json`。少数设置（端口、谁可以打开面板）在 GlintMiner 重启后生效；页面上会注明。

## 本机与你的钱包

面板把两类数据分开显示，并分别标注：

- **本机：** GlintMiner 对这台电脑的实时估算（算力、每日收益、功耗）。
- **你的钱包 · 所有矿机：** 矿池针对你整个地址的数据：余额、支付记录，以及挖到这个地址的每台矿机。

如果你有多台矿机挖到同一个钱包，余额和支付属于所有矿机的合计，而*本机* 数据只属于这台电脑。

**刚启动时，矿池会滞后。** 矿池报告的是 30 分钟平均值，每隔几分钟刷新一次，所以在最初 10–30 分钟内，矿池可能仍显示本机为 0（或重启前的数据）。面板会说明*矿池的数据还没更新*，而不是显示 0%。

## 数据无法刷新时

如果矿池或价格网站一段时间内无法访问（你的网络断了，或对方网站出了故障），挖矿会照常进行。面板会保留最后一次的数据，显示它们是多久以前的，并用一句简单的话说明哪些数据无法刷新。技术细节会写入 `glint.log`。

## 从其他设备打开

默认情况下只有挖矿电脑能打开面板。要在手机或笔记本电脑上查看：

- **在家，同一个网络：** 设置 → 面板 → **谁可以打开** → *其他设备*，保存并重启 GlintMiner，然后在另一台设备上打开 `http://<this PC's address>:4078`（这台电脑的地址）。
- **随时随地：** 使用 Tailscale，分步说明见[手机查看](phone-access.zh-CN.md)。

从其他设备打开时，面板**仅可查看**：可以看，但不能更改任何东西，页面上也会注明。如果也想允许从这些设备更改，请用 `--api-allow-remote-control` 启动 GlintMiner，仅限在你信任的网络中使用。

## 统计 API

GlintMiner 在同一端口上提供 JSON，供你自己的监控使用：

- `GET http://127.0.0.1:4078/api/stats`：算力（总计及每张显卡）、温度、风扇、功耗、份额、运行时间、版本、收益以及矿池的钱包数据。

HiveOS 和 MMPOS 从这里读取统计数据（`h-stats.sh`、`mmp-stats.sh`）。见[进阶](advanced.zh-CN.md#统计-api)。
