# 自动调校

[← 返回 README](../README.zh-CN.md) · [English](auto-tune.md) · [Русский](auto-tune.ru.md) · **简体中文**

每颗显卡芯片出厂时都略有不同。同型号的两张显卡，在相同电压下能稳定运行的频率可能不同，所以出厂设置是按最弱的那颗芯片来定的，以确保安全。自动调校会在显卡继续挖矿的同时，自动为**你的**显卡找到最佳的稳定设置。

它是**可选的，默认关闭**。默认情况下 GlintMiner 以出厂设置运行你的显卡，从不改动频率、电压或风扇。

## 能带来什么

在我们的 RTX 4090 上，于 Kryptex 实际挖矿：

| RTX 4090 | 算力 | 功耗 | 每瓦 TH/s |
|---|:-:|:-:|:-:|
| 出厂 | 310 TH/s | 443 W | 0.70 |
| **速度** | **332 TH/s**（+7%） | 430 W | 0.77 |
| **能效** | 310 TH/s | **338 W**（−24%） | **0.92** |

你的显卡结果会不一样，因为每颗芯片都不一样。很多显卡能多出几个百分点的算力，或以少五分之一到四分之一的功耗保持同样算力。余量很小的显卡可能找不到值得保留的设置，这时它就保持出厂设置（见[没有比默认更好的稳定设置](#提示信息的含义)）。

## 四种模式

| 模式 | 目标 | 适合 |
|---|---|---|
| **关闭**（默认） | 出厂设置 | 不想改动显卡的人 |
| **速度** | 显卡能零错误稳定运行的最高算力 | 电费便宜或免费；挖最多的 Pearl |
| **能效** | 以尽可能低的功耗保持出厂算力 | 电费贵、怕热、怕吵、电源功率小 |
| **利润** | 扣除电费后赚得最多 | 让 GlintMiner 根据价格来决定 |

**速度**模式在温度允许时，还可能把显卡的功耗上限提高到显卡自身的最大值。

**利润**模式需要填写电价（设置 → 电费）。它会先找出速度和能效两个结果，所以第一次调校大约要花两倍的时间。之后它每半小时根据币价和你的电价比较一次，运行收益更高的那个结果，只有另一个结果明显更赚钱时才切换（这样不会因为价格的小波动来回切换）。

**天气转凉时（仅限速度模式）。** 如果显卡之后明显比调校时更凉（寒冷的夜晚、清理过的风扇、更好的机箱），它还能再多撑一点。GlintMiner 会察觉到，在挖矿的同时再往上调一点，每天最多一次，并保留已保存的结果作为后备，以防新结果并不更好。

## 开始之前

调校测量的是很小的差别，每次约 1%，所以调校期间任何改变显卡速度的因素都会让结果变差。想要最好的结果：

1. **关闭其他超频工具**：MSI Afterburner、EVGA Precision X1、ASUS GPU Tweak、GIGABYTE AORUS Engine、GIGABYTE Graphics Engine、ZOTAC FireStorm、Palit ThunderMaster、GALAX Xtreme Tuner。最好把它们的配置恢复为默认，关掉 *启动时应用超频*，并关闭 NVIDIA App 的自动调优。在 Windows 上，只要这类工具在运行，GlintMiner 就会等待，并告诉你要关闭哪一个（仅开启 RivaTuner 的屏幕显示没有问题）。
2. **调校期间让电脑保持空闲。** 不要玩游戏、剪视频、运行本地 AI 应用或使用动态/视频壁纸。即使是挖矿电脑上一个有动画的浏览器标签页，也会占用显卡一点点性能。夜里最合适。
3. **已有的超频不用担心。** GlintMiner 开始前会把显卡恢复为出厂设置，所以调校从真正的出厂状态开始，关闭时再恢复你自己的设置。
4. **以管理员（Windows）或 root（Linux）身份运行。** 改动频率需要这些权限。在 Windows 上，开启调校后 GlintMiner 会提出以管理员身份重新启动自己；Windows 会请你确认。

## 如何开启

以下任选其一：

- **设置时：** 最后一个问题是 *Tune your card?*。选择一个模式，阅读那一句风险说明，然后输入 **Y**。
- **在面板中：** **设置 → 调优**，或首页上的 **设置调优** 按钮。
- **在命令行中：** `glint --tune speed --confirm-tuning`（也可用 `efficiency`、`profit`）。`--confirm-tuning` 只需第一次添加，用来确认你接受风险；它会被保存。

如果 GlintMiner 没有以管理员身份运行，显卡会以出厂设置挖矿，面板会显示*调优还无法开始*，并告诉你该做的那一件事：关闭 GlintMiner，右键点击它并选择 **以管理员身份运行**。之后调校会自动开始。

## 调校期间

- **显卡全程照常挖矿**，收益不会中断。
- **在高性能显卡上大约需要 1 到 1.5 小时**（能效模式更快，利润模式约为两倍）。面板会显示已完成的百分比和剩余时间。剩余时间只是估算：潜力更大的显卡会多花一点时间。
- **调校期间算力会略低。** 每个结果都要用 Pearl 官方校验器复核，这些检查会占用显卡一小部分性能。这是正常的。**请让它完成**：结果会在之后按显卡平常挖矿的方式测量，你看到的就是这个数字。
- **不要用调校期间的数字来判断结果。** 它们是有意偏低的，不代表最终结果。
- **可以随时暂停**（矿机 → **暂停这张显卡**）。显卡会立即恢复出厂设置，恢复后从中断处继续。
- **如果调校期间显卡崩溃**，那是调校在寻找显卡的极限，并不是故障。GlintMiner 会自动重启，把显卡恢复到安全设置并继续，一次调校中通常会发生几次。面板上可能显示*重启后继续调优*。它自行重启时绝不会再打开新的浏览器标签页。
- **如果调校期间显卡变热**，调校会等它降温后重做那一部分，所以房间偏热不会让结果永久变差。

## 调校完成后

面板会用简单的话显示结果，例如 **已调优 +7.4%**（速度）或 **功耗 −24%**（能效），以及与出厂相比的算力和功耗。

- **结果会被保存**，每次启动时自动应用，无需重新调校。
- **它会持续自我核对。** 在每一刻钟的正常挖矿中，显卡实际挖出的算力都会与显示的数字比较。如果显卡明显比这个数字快或慢，就会重新测量（每小时最多一次），让数字始终真实。
- **必要时它会自行回退。** 如果显卡在挖矿时出错，调校会退回到更安全的设置并说明（*出错后已退回到更稳妥的设置*）。如果应用调校后不久电脑死机或崩溃，下次启动也会使用更安全的设置。损失一点速度，总比显卡不稳定要好。
- **安装新的 NVIDIA 驱动**后显卡会重新调校，因为驱动可能改变显卡的表现。

## 多显卡矿机

- **一次只调校一张显卡**，从测量出厂算力到得出结果，所以测试一张显卡时不会测量其他显卡。其他显卡照常挖矿，已有调校结果的会使用各自的结果。排队等待的显卡会显示 *等待其他显卡完成调优*，它的剩余时间包括排在前面的显卡。
- **每张显卡都可以有自己的模式。** 例如一张用速度，另一张用能效，再一张保持出厂设置。没有单独设置的显卡跟随矿机的模式。可在 **设置 → 调优**（矿机模式下方的显卡列表）或 **矿机** 页面的每张显卡上设置；在那里还可以重新调校某一张显卡，或暂停它，其他显卡保持各自的调校结果。
- 命令行：`glint --tune-card 0=speed,1=efficiency,2=off --confirm-tuning`。未列出的显卡跟随 `--tune`。`--tune-exclude 0,2` 让这几张显卡保持出厂设置。
- **显卡重新编号时，模式和调校结果都不会丢失**：它们按显卡插槽保存。把显卡切回曾经调校过的模式时，会直接使用那次的结果。
- 首页会汇总显示，例如 *已调优 2/3 张显卡：GPU 0 +6.4%，GPU 1 功耗 −22%；GPU 2 保持默认*。

## 如何保护你的显卡

- **零错误，否则不用。** 只有在一段较长的持续测试中，每个结果都通过 Pearl 官方校验器，并且再留出安全余量后，这个设置才会被保留。
- **绝不超频显存，绝不超过显卡自身的最大功耗。** 速度模式可以提高功耗上限，但最多只到显卡本身允许的最大值。
- **一切都会恢复原样：** GlintMiner 关闭时，以及崩溃或断电后的下一次启动时。如果 GlintMiner 被强行结束（任务管理器），下次启动会先恢复显卡再做其他事，并且在显卡真正恢复之前不会显示它处于出厂设置。
- **导致电脑崩溃的调校结果绝不会原样再次应用。** 下次启动时会回退。
- **没有找到结果的搜索不会在每次启动时重复。** 显卡会保持出厂设置并注明原因，持续一周，或直到你重新调校、更新驱动或更新 GlintMiner。

## 温度上限

无论是否调校，GlintMiner 都会一直监控每张显卡的温度。

- **自动上限（推荐）：** 取自显卡自身的安全最高温度，略低于显卡开始自行降频的温度点。在 RTX 4090 上，出厂设置时为 80 °C，调校后为 83 °C（调校后的显卡可以使用它自身的安全最高温度）。绝不会设得高于显卡本身允许的值。
- **超过上限时**，GlintMiner 会小幅逐步降低显卡的功耗上限，直到温度回到上限以下（这需要管理员权限）。
- **接近显卡的关机温度时**，GlintMiner 会暂停这张显卡，直到它明显降温（即*紧急暂停*），然后继续挖矿。其他显卡照常挖矿。
- 你可以在 **设置 → 温度和功耗** 中自行设置上限。

## 重新调校、暂停与关闭

| 你想要… | 面板 | 命令行 |
|---|---|---|
| 从出厂设置重新调校 | 矿机 → **重新调优这张显卡** | `--retune` |
| 暂停调校 | 矿机 → **暂停这张显卡** | — |
| 更改模式 | 设置 → 调优 | `--tune efficiency` |
| 让某张显卡保持出厂设置 | 矿机 → 该显卡 → 模式 **关闭** | `--tune-exclude 0` |
| 关闭调校 | 设置 → 调优 → **关闭** | `--tune off` |
| 清除调校保存的所有内容 | — | `--tune-reset` |

关闭调校、暂停或关闭 GlintMiner，都会让显卡立即恢复出厂设置。

## 提示信息的含义

| 提示 | 含义 | 该怎么做 |
|---|---|---|
| **调优还无法开始** | GlintMiner 没有以管理员身份运行（Linux 上为 root） | 关闭它，右键点击，选择 **以管理员身份运行** |
| **MSI Afterburner 正在运行**（或其他工具） | 这个工具可能在调校途中改动频率 | 关闭它（并关掉它的*启动时应用超频*）；一分钟内调校会自动开始 |
| **等待其他显卡完成调优** | 一次只调校一张显卡 | 无需操作；轮到它时就会开始 |
| **重启后继续调优** | 显卡在测试极限时崩溃，或 GlintMiner 重启了 | 无需操作；调校期间这很正常 |
| **没有比默认更好的稳定设置** | 在这张显卡上，没有任何设置能零错误地超过出厂设置 | 无需操作；它保持出厂设置。可以改天再试，或在更新驱动后再试 |
| **已退回到更稳妥的设置** | 显卡在调校状态下挖矿时出错 | 无需操作；现在更安全了。如果愿意，之后可以点 **重新调优** |
| **这张显卡无法调优** | 驱动不允许改动这张显卡的频率 | 无需操作；它以出厂设置挖矿 |

## 坦白说明风险

自动调校会让显卡运行在出厂设置之外。它在第一个错误时就会回退，绝不超频显存，绝不超过显卡自身的最大功耗，并在 GlintMiner 关闭时（或崩溃后的下一次启动时）恢复一切。但不稳定的设置仍可能导致挖矿程序崩溃，极少数情况下导致显卡驱动或电脑崩溃。开启与否由你决定，风险自负；你不开启，它就一直关闭。
