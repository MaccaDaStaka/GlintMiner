## Командная строка

```
glint --wallet prl1... --worker rig1
glint --wallet prl1... --pool stratum+ssl://prl.kryptex.network:8048
glint --wallet krx... --worker rig1
glint --wallet BTC:bc1q... --kwh-price 0.12 --currency EUR
glint --wallet prl1... --devices 0,1 --api-bind 0.0.0.0 --plain
glint --wallet prl1... --tune speed --confirm-tuning --save
```

Параметры из командной строки действуют на этот запуск. Добавьте `--save`, чтобы записать их в `glint.json`, — тогда
простой запуск `glint` (или двойной щелчок) будет использовать их и дальше.

**Маршрут определяется кошельком:**

| `--wallet` | Где майнит | Выплаты в |
|---|---|---|
| `prl1…` (адрес Pearl) | HeroMiners, ближайший сервер (0% комиссия пула) | PRL |
| `prl1…` с `--pool stratum+ssl://prl.kryptex.network:8048` | Kryptex (2%, оплата за каждый шар) | PRL |
| `krx…` или email аккаунта Kryptex | Kryptex | BTC, вывод в BTC, USDT или USDC |
| `COIN:address`, например `BTC:bc1q…`, `DOGE:D…`, `SOL:…` | unMineable (1%) | Эта монета |

## Все параметры

| Параметр | Назначение |
|---|---|
| `--wallet ADDRESS` | Куда получать доход (см. таблицу выше) |
| `--coin TICKER` | Монета для адреса, который подходит нескольким (например, адрес `0x…`: ETH, USDT, …) |
| `--worker NAME` | Имя этого рига на пуле (буквы, цифры, `-` и `_`) |
| `--pool URL` | Этот пул вместо автоматического выбора (`stratum+ssl://host:port`) |
| `--devices 0,1` | Майнить только на этих GPU (номера как в `glint --gpu-info`); по умолчанию — на всех |
| `--kwh-price 0.12`, `--currency EUR` | Ваша цена электричества и валюта — для расчёта прибыли за вычетом электричества |
| `--profit-mode` | Раз в день подбирать самый выгодный лимит мощности (нужны `--kwh-price` и права администратора) |
| `--tune MODE` | Автотюнинг: `profit` (лучший заработок), `speed` (максимальный хешрейт), `efficiency` (меньше мощности), `cool` (холоднее и тише всего) или `off` (права администратора; в первый раз — `--confirm-tuning`) |
| `--confirm-tuning` | Подтверждает, что вы принимаете риск автотюнинга (сохраняется) |
| `--tune-card 0=speed,1=cool,2=off` | Свой режим для каждой карты (`default` — как у `--tune`); карты не из списка следуют `--tune` |
| `--tune-exclude 0,2` | Оставить эти карты на стоке, пока остальные настраиваются |
| `--retune` | Забыть сохранённые результаты тюнинга и заново настроить все карты со стока |
| `--tune-reset` | Забыть сохранённые результаты тюнинга, режимы карт и исключения и выключить тюнинг |
| `--tune-ignore-tools` | Настраивать, даже когда запущен MSI Afterburner или похожая программа (она может менять частоты посреди тюнинга) |
| `--schedule 23:00-07:00=cool,17:00-21:00=pause` | Часы для другого режима (`off`, `speed`, `efficiency`, `cool`) или паузы (`pause`); `--schedule off` выключает. См. [расписание](auto-tune.ru.md#расписание) |
| `--game-pause`, `--no-game-pause` | Windows: пауза майнинга, пока игра нагружает видеокарту (включена по умолчанию) |
| `--share-diff N` | Только Kryptex: сложность шара, которую запросить у пула (0 = автоматически) |
| `--api-port 4078` | Порт панели |
| `--api-bind 0.0.0.0` | Открыть панель для вашей сети (с других устройств — только просмотр) |
| `--api-allow-remote-control` | Разрешить с этих устройств и изменения (только в сети, которой вы доверяете) |
| `--open-dashboard`, `--no-open-dashboard` | Открывать или не открывать панель в браузере при запуске |
| `--telegram-token TOKEN`, `--telegram-chat ID` | Уведомления в Telegram, если карта остановилась или пропала связь с пулом |
| `--plain` | Простые строки лога вместо живой таблицы (службы, ОС для ригов, экранные дикторы) |
| `--no-log-file` | Не писать `glint.log` |
| `--save` | Записать эти параметры в `glint.json` |
| `--config PATH` | Другой файл настроек (по умолчанию `glint.json` рядом с `glint`) |

Полный список всегда есть в `glint --help`. Подробно об автотюнинге: [Автотюнинг](auto-tune.ru.md).

## Диагностика

| Команда | Что делает |
|---|---|
| `glint --self-test` | Проверяет карту, драйвер и код майнинга от начала до конца, затем завершается. Прикладывайте её вывод к сообщениям об ошибках |
| `glint --gpu-info` | Показывает ваши карты NVIDIA с их номерами, памятью, драйвером и compute capability |
| `glint --bench 60` | Майнит офлайн 60 секунд и сообщает хешрейт (результат сохраняется) |
| `glint --benchmarks` | Показывает сохранённые результаты замеров |
| `glint --pools ADDRESS` | Показывает, какой пул и маршрут будет использовать адрес |
| `glint --net-test host:port` | Проверяет соединение с сервером пула |

## Несколько видеокарт и несколько ригов

- **Один ПК, несколько карт.** GlintMiner автоматически использует все поддерживаемые карты NVIDIA в ПК, модели можно
  смешивать (например, 3080 и 4070). У каждой карты своя строка в консоли и на панели: свой хешрейт, температура,
  мощность и шары. Карты делят одно подключение к пулу, поэтому пул видит одного воркера на ПК.
- **Выбор карт для майнинга:** `--devices 0,2` или Настройки → Майнинг → Какие карты использовать.
- **Сбой одной карты не останавливает остальные.** Если карта не запустилась, остальные продолжают майнить, а консоль
  сообщает причину. Если карта перестала отвечать, GlintMiner перезапускается и продолжает работу.
- **О каждой карте заботятся отдельно:** температурная защита и автотюнинг работают с каждой картой по отдельности.
  См. [Риги с несколькими картами](auto-tune.ru.md#риги-с-несколькими-картами).
- **Несколько ПК:** запускайте GlintMiner на каждом со своим именем воркера (`--worker rig2`), все на один кошелёк.
  Пул показывает каждый ПК отдельно, а страница «Доход» на панели — все риги на этом кошельке.
- **Память:** рассчитывайте примерно на 1,5 ГБ оперативной памяти (RAM) на каждую GPU.

## Пулы и выплаты

- **Автоматический выбор пула.** Для адреса Pearl GlintMiner выбирает ближайший сервер HeroMiners и переключается на
  другой, если тот становится недоступен. Соединения шифруются (TLS).
- **Свой пул:** `--pool stratum+ssl://host:port` или Настройки → Майнинг → Свой пул.
- **Шары меньше на HeroMiners и Kryptex.** Шар Pearl весит около 2 МБ. На HeroMiners GlintMiner отправляет их сжатыми
  (около 14 КБ каждый); если какой-то сервер HeroMiners их не примет, до конца работы этому серверу отправляются
  несжатые шары. На Kryptex шары сжимаются (около 11 КБ), если Kryptex соглашается на это при входе. Меньше трафика и
  меньше устаревших шаров на медленном соединении.
- **Сложность шара на Kryptex.** Большой риг (больше 500 TH/s) автоматически просит у Kryptex более высокую сложность
  шара — примерно один шар в 30 секунд, чтобы не засыпать пул шарами. Свою можно задать через `--share-diff N`.
  По умолчанию у Kryptex 2097152; формула: *хешрейт в H/s × секунд на шар ÷ 4294967296*. Заработок от этого не
  меняется: каждый шар просто стоит больше.

## HiveOS, MMPOS, Docker и службы Linux

- **HiveOS:** добавьте кастомный майнер по ссылке на `glint-….tar.gz` из Releases. Пошагово, включая статистику
  и открытие панели с другого компьютера: [HiveOS](../hiveos/README.md).
- **MMPOS:** [MMPOS](../mmpos/README.md).
- **Docker:** [Docker](../docker/README.md). На хосте нужен NVIDIA Container Toolkit.
- **Служба Linux (systemd):** скопируйте [`glint.service`](../glint.service) в `/etc/systemd/system/`, впишите в него
  свой кошелёк и выполните `systemctl enable --now glint`. Тогда GlintMiner запускается при загрузке и перезапускается,
  если вдруг остановится. Для служб используйте `--plain`, чтобы лог нормально читался в `journalctl -u glint`.
- **Автотюнингу в Linux** нужен root, потому что без него частоты не изменить.

## API статистики

GlintMiner отдаёт JSON на порту панели — для вашего собственного мониторинга и для ОС для ригов:

- `GET http://127.0.0.1:4078/api/stats`: общий хешрейт и хешрейт по картам (H/s), температуры, вентиляторы, мощность,
  шары (принятые, отклонённые, устаревшие), время работы, версия, оценка дохода и данные пула по кошельку.
  `status.state` равно `held`, пока майнинг на паузе из-за игры или по расписанию, а `hold` говорит, почему
  (`{"kind": "game", "program": "…"}` или `{"kind": "schedule", "until": "07:00"}`).

API отвечает только на `127.0.0.1`, если не запустить GlintMiner с `--api-bind 0.0.0.0`. Хешрейт — в H/s, где 1 H —
это одно умножение-накопление Pearl.

## Файлы GlintMiner

Все лежат рядом с программой (или рядом с файлом, указанным в `--config`):

| Файл | Что в нём |
|---|---|
| `glint.json` | Ваши настройки, сохранённые результаты тюнинга (по одному на карту и режим), расписание и программы, которые не ставят майнинг на паузу. Сохраняйте его при обновлении; удалите, чтобы пройти настройку заново |
| `glint.log` | Лог: что и когда произошло, с техническими подробностями любых ошибок. Прикладывайте нужные строки к сообщениям об ошибках |
| `glint-history.jsonl` | Поминутная запись хешрейта, мощности и дохода — для графиков и итогов на панели |
| `glint-benchmarks.json` | Результаты `--bench` |

Паролей ни в одном из них нет. В `glint.json` хранятся ваш адрес для выплат и, если вы их указали, токен Telegram-бота
и chat id.
